# HR_project

## Project Description
This is a Python-based HR Application Management System.

## Features
- Add candidate applications
- View all applications
- Allow candidates to view their own applications
- Store application data in JSON

## Technologies
- Python
- Poetry
- Ruff
- Mypy
- Pytest

## How to Run
```powershell
poetry install
poetry run python HRapplication.py
```

## How to Test
```powershell
poetry run pytest
```
